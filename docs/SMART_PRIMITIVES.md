# Smart Primitive experiment removed (v0.24.1)

The experimental Smart Primitive workflow was removed on 2026-11-08 at the user's request. The user reported unsatisfactory behavior and chose to focus this Blender tool on offline animation correction. Add Primitive, Edit Primitive, temporary-rig edit mode, box/curve encounter planning and Generate Route are no longer registered or displayed.

The previous source and experimental notes are archived under `development/removed_smart_primitives/v0.24.0/`, outside the installed addon. The feature is not resumed automatically. Native pose constraints, multiple simultaneous Kimodo/ARDY goals, ordinary MotionBricks blocks, Path Curves for Kimodo/ARDY, and native NLA/correction playback remain available.

## Existing scenes

Opening an older scene retains its wire boxes, collections, saved pose JSON, referenced pose Actions, draft armature and native generated NLA animation. Existing route results become ordinary animation blocks. A one-time compatibility reader restores main-rig visibility, playhead and range if the scene was saved in the old editor. For a saved pending route, previous blocks are restored to ordinary enabled blocks and ungenerated replacement drafts are retained as disabled blocks. No boxes, draft keys or Actions are automatically deleted, and input `.blend` files are not overwritten.

Old pose data is archival; regeneration now uses the main rig's ordinary native pose keys. There is no implicit route regeneration. Users can inspect or remove retained objects with Blender's standard tools.

## Validation

`results/blender_bridge/primitive_removal.json` verifies absent operators/properties/UI, old edit/completed/pending scene loading, preserved source keys and NLA, retained pose assets/drafts, save/reopen and unchanged original files. Existing `pose_constraint_ui.json` and `layered_corrections.json` pass for multiple constraints, key lifecycle and native layered playback. Tests use separate Blender 5.2.3 background instances; the user's GUI is not automated.

The installer removes only obsolete files listed in its previous deployment receipt after checking for local modifications; generated bytecode for those files is removed too. Restart Blender to load v0.24.1. The companion app does not need a restart.
